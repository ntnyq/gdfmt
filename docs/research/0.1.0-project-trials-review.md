## Fixed review-guard defect

The comparator classifier previously ignored **every colon** when explaining
an inner-class `extends` difference. Consequently, loss of an unrelated type
annotation colon could be accepted as that category, including when mixed with
a legitimate class-header move. This weakened the review guard, even though the
Rust invariant gate remained independent.

The classifier now normalizes only `class Name: extends Base` to the matching
inline-header token sequence, including qualified base names. Body, annotation,
dictionary and suite colons remain significant. Two focused regression tests
cover unrelated colon loss, mixed legitimate/unexplained changes, multiple
headers, qualified bases, preserved body colons and comparison in both directions.
The rejection regression failed before the fix and passes afterward. The fix
changes only trial tooling; Rust formatting, defaults, schema and reviewed
fingerprints remain unchanged.
