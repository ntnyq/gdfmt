## Real registry consumers

The CI publishers installed the exact crates.io CLI and isolated npm native/WASM/CLI
consumers on Linux before completing the release. Additional macOS ARM64 consumers
used fresh public-registry installs outside the repository:

- Rust 1.98 installed `gdfmt_cli` at `=0.1.0-rc.1`. The installed executable passed
  version and Unicode stdin checks. A standalone locked Rust consumer resolved all
  eight release crates from the registry, then tested the facade, idempotence,
  invalid-source diagnostics, decimal/exponent configuration and public CLI runner.
- Node 24.22.1 installed native and WASM packages through `next`, with optional
  dependencies enabled, and confirmed exact rc.1 versions and registry integrity.
  ESM, CommonJS, async API, configuration, strict option validation, diagnostics,
  CLI and installed declarations passed. Native/WASM results matched for all
  1,465 fixture/profile combinations.

Supported Node versions remain 22.13+ on 22.x or 24.x. Browser/Worker host acceptance
comes from the tag-bound CI, and registry WASM bytes match those tested bytes.
No new host or full Godot compatibility claim is added.
