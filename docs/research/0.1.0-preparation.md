## Source identity and scope

plus the uncommitted version and documentation changes in this working tree.
No commit, tag, release workflow, registry write, dist-tag change or Marketplace
upload was created. Existing local editor settings are excluded and preserved.
This is `cleanSource: false`, `published: false` evidence, not a final frozen revision.

`pnpm release:version 0.1.0 --dry-run` and the actual local version update passed.
Reviewed changes cover the workspace version, seven exact internal requirements,
eleven Cargo lockfile entries, both public npm manifests, five exact optional
native dependencies and extension `gdfmtVersion`. Generated platform packages
inherit 0.1.0. Private npm tooling versions and the pnpm lockfile are unchanged.
The stable version selects `latest` in release planning; no registry channel was moved.

The extension uses independent numeric **0.2.1**, higher than the published rc.1
GitHub VSIX's **0.2.0**, so the two payloads have distinct extension versions.
A fresh `pnpm exec vsce show ntnyq.gdfmt --json` read listed all six Gallery targets
only at prerelease **0.1.0**; 0.2.1 was unused at this snapshot. This does not reserve
that version. Recheck before any upload. The official
[VS Code publishing rules](https://code.visualstudio.com/api/working-with-extensions/publishing-extension#pre-release-extensions)
require numeric versions and separate numeric versions for prerelease/stable Gallery uploads.
Core-version filenames remain `gdfmt-0.1.0-TARGET.vsix`. Stable core packaging removes
the VSIX prerelease flag; final six-target freezing remains pending.

No formatter implementation, defaults, API declarations, configuration contract or
generated Schema changed. Documentation keeps the published rc.1 install commands;
0.1.0 release notes remain drafts. Historical rc.1 reports and receipts keep their
original revisions and versions.
