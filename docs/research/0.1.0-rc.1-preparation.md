## Release-test fixture correction

The legacy six-package recovery test cloned committed source but built synthetic
archives from current manifests. With an uncommitted alpha.6 → rc.1 update it
failed on a legitimate source/archive version mismatch (31/32 tests passed).
The fixture now copies current matching source manifests before modeling the
legacy source without WASM and committing its isolated fixture. The suite then
passes 32/32. No production recovery validation was relaxed and no real package
was published by these synthetic tests.
