Status: preparing the candidate branch and PR; full CI pending. No tag or
publication is authorized in this step. The [initial preparation](0.1.0-rc.1-preparation.md)
remains historical dirty-source evidence.

## Scope

Commit the reviewed candidate changes while excluding the maintainer's local
editor settings. Core and npm versions remain `0.1.0-rc.1`; extension numeric
version remains `0.2.0`. Default formatter style is unchanged.

The desktop acceptance runner now also installs the generated VSIX in a fresh,
isolated profile, verifies extension/core versions, compares the installed server
bytes and checks stdin formatting. Desktop freeze acceptance requires
`installedVsixPassed: true`; missing/false evidence is regression-tested. Alpine
retains native smoke acceptance; Web retains its distinct virtual-filesystem host.

The desktop regression suite now waits for the document-change notification
when checking undo, because an Extension Host command acknowledgement can arrive
first. It requires exact restoration of the pre-format document with a bounded
failure timeout; formatting and undo behavior are not changed.

## Required evidence

Record the exact candidate commit, PR, complete Rust/npm/host workflow runs,
ten Node consumer receipts, WASM and all six VSIX receipts. Review artifact
hashes and clean-source/commit identity before acceptance. Repeat the complete
pinned project trial in a clean checkout. Registry/OIDC and publication gates
remain separate; creating a PR or passing CI does not publish the candidate.
