without `--allow-dirty`. Every archive's VCS revision matches the clean source.

and intended version. PR merge-preview receipts use their synthetic merge revision
and are excluded from this exact-source bundle.

Complete local `pnpm verify:npm` passed with ten receipts and `completeMatrix: true`.
`pnpm release:prepare` assembled and validated seven npm tarballs, eight crate
archives and six VSIX files. All VSIX manifests use core 0.1.0 / extension 0.2.1
and omit the prerelease property. Four desktop targets passed isolated installed
VSIX checks, Alpine passed native smoke, and Web passed its real virtual-filesystem
host. Staged Web acceptance does not establish an end-user Gallery installation.

This is a clean-source preparation rehearsal, **not a final tag-bound release
freeze**. A future squash/merge commit must rerun its own validation. Registry
installation instructions still use published rc.1; 0.1.0 notes remain drafts.
