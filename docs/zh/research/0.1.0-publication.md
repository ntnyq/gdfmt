## Registry 与真实消费者

[机器可读证据](../../research/0.1.0-publication.json)记录所有包 hash、公开发布身份、
渠道、消费者回执及 GitHub 附件。八个 crate 均未 yank，下载 SHA-256 与 Cargo VCS
身份匹配原 bundle；全部 `trustpub_data` 指向 GitHub、`ntnyq/gdfmt`、本次运行及提交。
七个 npm 下载均匹配冻结 SHA-512 integrity 和 registry SHA-1，带 GitHub Trusted
Publishing 与 provenance 元数据。七个 `latest` 均推进到 0.1.0，`next` 保持 rc.1，
`candidate` 指向正式版。

CI 在 Linux 安装精确 crates.io CLI，并运行 npm 原生/WASM/API/CLI 消费者。
独立 macOS ARM64 验收从 crates.io 安装八个 Rust crate，覆盖 facade、配置、诊断和
CLI runner，并以 `gdfmt_cli =0.1.0 --locked` 安装 CLI。仓库外隔离 npm 消费者安装
`@gdfmt/gdfmt@latest` 与 `@gdfmt/wasm@latest`，精确解析为 0.1.0 及匹配的原生
optional 依赖。ESM、CommonJS、异步 API、声明、配置、严格校验、诊断与 CLI 通过；
原生/WASM parity 覆盖 **1,465** 个 fixture/profile case。
