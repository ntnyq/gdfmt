## 范围与版本同步

审查基准为 `6c11445a329b688f27fd6693a3c6314ffeedce64` 与当前工作区的差异，
包括新文件，尚无候选提交。已有的本地编辑器设置改动不计入候选工作。本地回执
如实记录 `cleanSource: false`，不能仅凭基准提交标识这些未提交修改。

`release:version 0.1.0-rc.1` 的 dry-run 与更新检查通过：workspace 版本、七条内部
精确依赖、Cargo.lock 十一个本地项、两个公开 npm 清单、五个可选原生依赖和扩展
`gdfmtVersion` 已同步。扩展独立数字版本为 `0.2.0`，私有根目录/文档工具版本及
Schema 契约不变。本次没有创建提交、ref 或发布，默认格式化布局实现未改动。

只读精确版本查询中，八个 crate 和七个 npm 包的 rc.1 均返回 404。Gallery 元数据
仅列出数字版本 `0.1.0`，且未被截断；快照时 `0.2.0` 可用。这不预留版本，也不能
证明 Trusted Publisher 权限。保留维护者之前的配置完成确认；新的认证证据和
授权的新版本真实发布仍是独立清单门槛。

`CONTRIBUTING.md` 审查 Rust/JavaScript/TypeScript 变化、回归，以及新增清单、
研究和发布文档。纯校验仍在配置层；CLI/输出路由及编辑器 I/O 留在宿主层。
没有新增手写 unsafe 或无关抽象，保留布局默认值。此为静态审查，与下面的执行
检查分别记录。
