# 0.1.0 安装与文档审查

[English](../../research/0.1.0-documentation-review.md)

于 2026-10-23 审查基于 `6c11445a329b688f27fd6693a3c6314ffeedce64` 的
`0.1.0-alpha.6` 工作区，包含此前契约修复。双语说明现已与该基线一致；
选择最终发布候选版本时，仍需复核示例中的版本与 registry 渠道。

后续[分发审查](0.1.0-editor-distribution-review.md)依据实际 VSIX 清单修正了
已打包 Web 的信任和浏览器安装说明，当前指南已包含这些修正。

## 修正内容

| 范围        | 修正                                                                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 安装        | 显式指定 Cargo 预发布版本，区分 `gdfmt_cli` 包名与 `gdfmt` 命令；补充 npm 运行时要求、WASM 安装命令，以及使用 lockfile 或已审查 revision 的可复现 CI 安装方式。       |
| 源码构建    | 说明依赖安装、固定 Rust 工具链及仓库声明的 pnpm 版本；Web 构建还需 wasm-pack 与 WASM 目标。安装已构建的原生 VSIX 无需额外安装 Node。                                  |
| Schema 导出 | 两种语言的 Node 参考及 npm README 将错误的 `gdfmt/schema.json` 改为 `@gdfmt/gdfmt/schema.json`，并通过安装包验证 ESM 解析。                                           |
| 配置示例    | 说明先创建继承的 base/team 文件，再运行示例；全部十份双语配置块经过实际 CLI 校验。                                                                                    |
| API 示例    | npm README 在格式化前检查 `resolution.ignored`，并明确布局选项位于 `options.format`；区分省略参数和显式 `undefined` 属性值。                                          |
| 类型声明    | 补充数值范围/默认值、结构换行、字节比较、WASM 辅助方法上限及配置元数据的 JSDoc；本次文档审查不改变签名或运行时行为。                                                  |
| 编辑器设置  | 说明源码前置条件、远程扩展宿主的原生目标及使用核心版本的 VSIX 文件名；未命名缓冲区使用默认配置，但其桌面会话可采用可信环境中的全局 `serverPath`，并非总选择内置程序。 |

旧 CI 说明仍假设发布包不可用。审查时，[原生 npm `next` 接口](https://registry.npmjs.org/@gdfmt%2Fgdfmt/next)
与 [WASM npm `next` 接口](https://registry.npmjs.org/@gdfmt%2Fwasm/next) 均返回
`0.1.0-alpha.6`；[Cargo 包元数据](https://crates.io/api/v1/crates/gdfmt_cli)显示该预发布
版本为最新版本，尚无正式版本。这些是有日期的核查结果，不保证移动标签始终不变。
切换正式渠道的最终说明仍保留为发布阶段检查项。

## 验证

- 根 README 与配置指南的十份 JSON/JSONC 示例，在提供继承文件后均通过
  `gdfmt explain-config`；两种语言的快速开始和布局示例均与 CLI 精确输出一致。
- 五段原生 API 文档示例及带 scope 的 Schema 导出，在安装后的本地 tarball 中运行
  通过；三段显式字节加载的 Node/WASM 示例也通过安装包验证。三份 VS Code 设置
  示例与扩展声明的语言/formatter 标识及保存格式化设置一致。
- `pnpm test:npm`：本地 `darwin-arm64` 的八项消费者测试通过，包括安装后的
  ESM/CJS 声明及 CLI 行为。
- `pnpm test:wasm`：Node 与 Chromium 的 1,465 组 fixture/profile、Worker、
  上限及安装包声明检查通过。
- `pnpm typecheck`、`pnpm typecheck:docs`、`pnpm docs:build` 通过。双语清单
  的 22 项逐项一致，其中 7 项完成；本地报告/清单链接有效，`git diff --check` 通过。

本轮没有改变 formatter 实现、默认风格、配置接受行为、公开签名或包版本。
完整候选版本矩阵、最终产物的 registry 安装、Marketplace 发布和最终文档部署
仍是独立发布验收项。
