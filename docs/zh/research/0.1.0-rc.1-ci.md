# 0.1.0-rc.1 候选提交与 CI

[English](../../research/0.1.0-rc.1-ci.md)

状态：候选已提交到 [PR #1](https://github.com/ntnyq/gdfmt/pull/1)，正在收集完整
CI 及产物验收证据。本步骤不授权创建 tag 或发布。
[最初准备报告](0.1.0-rc.1-preparation.md)仍作为非干净源码的历史证据保留。

## 范围

提交已审查的候选改动，排除维护者本地编辑器设置。核心与 npm 版本保持
`0.1.0-rc.1`，扩展数字版本保持 `0.2.0`，默认格式化风格不变。

桌面验收 runner 现在会在全新隔离配置中安装生成的 VSIX，检查扩展/核心版本、
比较安装后的 server 字节并验证 stdin 格式化。桌面冻结要求
`installedVsixPassed: true`，并回归测试缺失/false 回执的拒绝。Alpine 保留原生
smoke 验收，Web 保留独立的虚拟文件系统宿主验收。

桌面回归检查撤销时改为等待文档变更通知，因为 Extension Host 命令回执可能
先到达；有界超时内必须精确恢复格式化前的完整文档。没有改变产品的格式化或
撤销行为。

## 所需证据

记录精确候选提交、PR、完整 Rust/npm/host 工作流，十份 Node 消费者回执、
WASM 及六份 VSIX 回执。验收前检查产物 hash、干净源码及提交身份，并在干净
checkout 重跑完整固定项目试用。Registry/OIDC 与发布门槛独立保留；创建 PR 或
通过 CI 不会发布候选版本。
