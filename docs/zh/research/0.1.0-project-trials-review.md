没有发现格式化输出回归或默认风格变化。

## 已修复的审查守卫缺口

此前比较器分类器在解释内部类 `extends` 差异时，会忽略**所有冒号**。因此，
无关的类型注解冒号丢失也可能被错误接受为该类别；即使与正常的类头位置变化
混合出现，也可能漏检。独立 Rust 不变量门槛仍然存在，但审查守卫范围过宽。

现在仅将 `class Name: extends Base` 归一化为对应的行内类头 token 序列，
支持限定名称的基类，保留类体、类型注解、字典与 suite 冒号的意义。新增两个
定向回归，覆盖无关冒号丢失、正常/异常变化混合、多个类头、限定基类、保留
类体冒号及双向比较。拒绝回归在修复前失败、修复后通过。修改仅涉及试用工具，
Rust 格式化、默认值、Schema 和审查指纹均未变化。
