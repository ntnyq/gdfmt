## 真实 registry 消费者

CI 发布 job 在 Linux 安装精确版本的 crates.io CLI，并在隔离环境安装 npm 原生/
WASM/CLI 消费者后才完成发布。额外的 macOS ARM64 验收在仓库外全新安装公开包：

- Rust 1.98 安装 `gdfmt_cli =0.1.0-rc.1`，检查实际可执行文件的版本及 Unicode stdin。
  独立、锁定依赖的 Rust 消费者从 registry 解析全部八个发布 crate，检查 facade、
  幂等性、无效源码诊断、小数/指数配置和公开 CLI runner。
- Node 24.22.1 通过 `next` 安装原生与 WASM，保留可选依赖，确认精确 rc.1 版本及
  registry integrity。ESM、CommonJS、异步 API、配置、严格选项校验、诊断、CLI
  和安装后的声明均通过；1,465 个 fixture/profile 组合的原生/WASM 结果全部相同。

支持范围仍为 Node 22.x 的 22.13+ 或 24.x。浏览器/Worker 宿主验收来自绑定 tag 的
CI，registry WASM 字节与已测试字节相同，不新增宿主或完整 Godot 兼容性承诺。

## 精确 tag 的项目试用

干净 tag checkout 在不带 `--record-review` 的条件下，以 Python hash seed 149
通过 14 项守卫及完整固定项目试用。606 个审查条目和四份报告 hash 与此前验收
候选相同：605 个接受脚本、2,420 种不变量布局、一个预期源码拒绝、九个比较器
拒绝、67 个相同输出、529 个已解释差异、零未解释差异。

## 安装与剩余工作

```sh
cargo install gdfmt_cli --version '=0.1.0-rc.1' --locked
pnpm add -D @gdfmt/gdfmt@0.1.0-rc.1
pnpm add @gdfmt/wasm@0.1.0-rc.1
```

也可使用 `next`，需要可复现时固定版本或提交 lockfile。默认格式化风格及公开
Schema 版本不变。正式版本同步、最终正式 tag 的 CI/冻结、`latest` 推进及最终
安装/文档完成检查仍见[发布检查清单](https://github.com/ntnyq/gdfmt/blob/main/RELEASE_CHECKLIST.zh-CN.md)。
Marketplace 上传独立处理，本地编辑器设置已保留。
