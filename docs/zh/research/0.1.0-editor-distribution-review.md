# 0.1.0 Marketplace 与 VSIX 准备情况审查

[English](../../research/0.1.0-editor-distribution-review.md)

于 2026-10-23 审查基于 `6c11445a329b688f27fd6693a3c6314ffeedce64` 的
`0.1.0-alpha.6` 工作区。本轮给出分发方案和准备情况，不发布，也不修改两种版本号。

## 0.1.0 建议方案

以 GitHub Release 的六份冻结 VSIX 作为发布交付基线，原生用户直接安装匹配产物。
Marketplace 正式发布作为独立后续工作，不阻塞核心发布；完成下方准备后可与
0.1.0 同步，否则保留现有 Marketplace 预发布，并明确它不是最终核心版本。
对于纯浏览器用户，需要区分 Web 产物与安装入口：存在 Web VSIX 不代表所有
浏览器版 VS Code 都支持从本地 VSIX 安装。

## Marketplace 公开状态

公开查询 `pnpm exec vsce show ntnyq.gdfmt --json` 找到了现有
[条目](https://marketplace.visualstudio.com/items?itemName=ntnyq.gdfmt)：数字扩展版本
**0.1.0**、**预发布**，覆盖 `darwin-arm64`、`darwin-x64`、`win32-x64`、
`linux-x64`、`alpine-x64`、`web`。Gallery 的 macOS ARM64 与 Web 清单均记录核心
**0.1.0-alpha.6**。因此，不能声称“尚未上架”，也不能将扩展数字版本 0.1.0 当作
核心正式版 0.1.0。

只读公开查询证明历史发布存在，不能证明当前操作者的 publisher 成员权限或认证
可用。仓库已有打包和 Release 附件 job，但没有 Marketplace 发布 job，也没有
未来正式版 Gallery 上传的恢复流程或安装验收证据。

## 两条路线对比

| 范围         | GitHub VSIX                                                                                 | Marketplace                                                                         |
| ------------ | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 现有实现     | 原生/Web 打包、平台回执、干净源码/版本/hash 检查、冻结和 Release 附件。                     | 公开可见六种预发布变体；仓库没有 Gallery 发布工作流。                               |
| 验收证据     | 本地 macOS ARM64 与 Chromium Web 宿主回执存在，`cleanSource: false`；最终候选矩阵仍需重跑。 | 公开 macOS/Web 清单对应 alpha.6；当前 publisher 权限、正式上传及正式版安装未验证。  |
| 版本标识     | 文件名与 `gdfmtVersion` 标识核心，manifest `version` 是独立数字扩展版本。                   | 数字 `0.1.0` 已被预发布占用；正式版需新版本，建议 **0.2.0**，构建前重新核对可用性。 |
| 更新方式     | 用户手动下载并安装指定版本。                                                                | Gallery 发现/更新要求六种变体统一规划新的数字版本。                                 |
| 纯浏览器场景 | 保留 Web 产物；不支持本地 VSIX 时使用已测试的开发宿主，或官方说明的托管地址侧载。           | 现有用户可安装 Gallery 预发布；最终核心正式版依赖后续正式 Gallery 上传。            |

微软要求预发布与正式上传使用不同数字版本，并支持发布已打包的平台 VSIX。
六种目标应采用同一新数字版本，认证后发布冻结字节，不从 `editors/vscode/`
重新构建上传。详见[官方发布指南](https://code.visualstudio.com/api/working-with-extensions/publishing-extension#pre-release-extensions)。

## 已验证内容

本地 macOS 与 Web VSIX 归档均匹配回执 SHA-512，身份均为 `ntnyq.gdfmt`，数字
版本 `0.1.0`、核心 `0.1.0-alpha.6`，均带预发布标记。原生包有 `main` 和程序，
没有 `browser`；Web 包有 `browser`、Worker 和 WASM，没有 `main` 或原生程序。
staging 会删除 workspace 依赖。

归档安装 smoke check 使用隔离的 VS Code 1.96.4 profile 与扩展目录：安装 macOS
ARM64 VSIX、列出 `ntnyq.gdfmt@0.1.0`，并检查安装后程序的精确核心版本。不修改
用户 profile，也不代表最终候选或跨平台验收。现有宿主测试加载开发/staging
目录，本身不能证明冻结 VSIX 或 Gallery 安装成功。

另一份隔离的 macOS ARM64 检查从 Gallery 以预发布选项安装 `ntnyq.gdfmt@0.1.0`，
列出扩展，并确认安装后程序为 `gdfmt 0.1.0-alpha.6`。这证明现有预览安装路线可用，
不代表未来正式上传或对应升级路径通过验收。

## 修正安装与信任说明

[官方安装指南](https://code.visualstudio.com/docs/configure/extensions/extension-marketplace#install-from-a-vsix)
说明 VSIX 安装方式；通过 VSIX 安装的扩展默认关闭自动更新。应使用
**gdfmt: Show Version** 核对核心，不能只看数字扩展版本。

已测试的 VS Code 1.96.4 仅在存在本地或远程扩展管理 server 时提供本地 VSIX
安装，单独的浏览器 Web 宿主不足以提供该入口，见
[固定版本的命令注册](https://github.com/microsoft/vscode/blob/1.96.4/src/vs/workbench/contrib/extensions/browser/extensions.contribution.ts#L804-L838)。
微软将[托管地址侧载](https://code.visualstudio.com/api/extension-guides/web-extensions#test-your-web-extension-in-vscode-dev)
记录为开发测试路线。仓库的 `pnpm test:vscode:web` 验证 staging 开发宿主，
不代表最终用户在 `vscode.dev` 中安装成功。

归档检查还纠正了此前只看源码清单的误判：`stageExtension(..., 'web')` 将能力声明
替换为完整的未信任/虚拟工作区支持。Web 的 `configPath` 在未信任工作区可用，
仍受相对路径和所属工作区边界限制。只有桌面端在信任前限制工作区 `configPath`
及自定义程序。指南、发布说明与此前审查记录均同步修正。

## Marketplace 正式发布前仍需完成

1. 验证当前 publisher 成员权限及受支持的发布身份；公开元数据不能证明这两项。
   检查条目文本、支持链接及正式版本号可用性。
2. 最终核心更新为 `0.1.0` 时，选用新的数字扩展版本（建议 `0.2.0`，以重新查询
   Gallery 为准），统一构建、测试和冻结六种变体。不能将 Gallery 预发布 0.1.0
   直接复用为正式上传。
3. 增加或记录单独授权的冻结 VSIX 发布流程，逐目标记录结果及部分上传恢复。
   Cargo/npm Trusted Publisher 不负责 Marketplace 发布。
4. 在桌面、远程宿主及纯浏览器 Web 中验证正式 Gallery 目标选择、干净 profile
   安装、格式化及版本显示，另行检查预发布到正式版的更新路径。
5. 上述检查通过后再宣布 Marketplace 正式版可用；此前保留原生 VSIX 路线，并
   正确标注现有 Gallery 预发布及 Web 开发/侧载方式。

图标和扩展 changelog 可以完善条目，但缺失并不等于无法发布。本轮没有读取发布
凭据，没有 Gallery 写入、版本更新或用户 profile 安装。
