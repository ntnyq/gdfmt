尚未发布的工作区。

## 本次候选已审查的变化

- 按 Schema 接受整数值小数/指数 JSON 配置，保留范围校验及局部配置限制。
- I/O 前检查 CLI 参数冲突，保留 JSON 诊断路由，LSP 与格式化开关互斥。
- 拒绝 JavaScript 不支持的自有属性，包括不可枚举属性和 symbol；对齐 WASM
  初始化声明与运行时检查。
- 编辑器拒绝不能精确保留混合换行的编辑，保持整文档格式化；补回归并明确
  桌面/Web 配置和信任差异。
- 加固实际 workspace 版本字段与独立扩展数字版本的同步检查。修复旧版恢复
  测试夹具，使未提交版本更新时也使用匹配源码清单；生产恢复仍拒绝版本、hash、
  提交不一致的产物。
- 将项目试用比较器对内部类 `extends` 的归一化限定为对应类头冒号，保留函数体、
  字典及 suite 中的冒号差异。
- 桌面产物冻结新增要求隔离的 VSIX 实际安装验收，并回归测试缺失/false 回执的
  拒绝。隔离桌面测试配置，等待内置宿主保存链路就绪，保留严格缓冲区/磁盘与撤销断言。
- 更新中英文安装、API、编辑器、迁移与发布文档。

## 支持范围、默认值与迁移

候选沿用[计划中的 0.1.0 支持及迁移契约](0.1.0.md)：Rust 1.88+、CLI、Node 22.x
的 22.13+ 或 Node 24.x、浏览器 ESM/module Worker、stdio LSP、VS Code 1.96+
桌面及独立 Web 扩展。原生目标为 macOS ARM64/x64、Windows x64 MSVC、Linux
x64 glibc/musl；Godot 语法 profile 为 4.3–4.7，默认 4.7。

**默认格式化风格保持不变**：行宽 100、Tab 显示宽度 4、配置宿主使用 LF、最多
保留两行现有空行、文件末尾换行。纯 Rust facade 默认保留源码换行。现有标点、
字面量词形、注释及保护区域字节保持保留；行宽是受支持断点的目标，不是硬上限。

从 `gdformat` 迁移时，从干净项目开始，手动将配置转换为 `.gdfmtrc.json`，检查
`gdfmt --diff .`，将格式化与行为变更分开，并运行项目的 Godot 检查。详见
[完整迁移步骤](0.1.0.md#从-gdformat-迁移)。

## 已知限制及剩余验收

不声明完整 Godot 兼容性或运行时等价，不提供 lint/语义修复、范围格式化、Godot 3
或通用 WASI/Bun/Deno 支持。Web 配置拒绝 overrides、配置 ignore 及发现的
EditorConfig；混合换行输出可能需 CLI。长表达式与保留内容可以超出行宽，详见
[完整限制](0.1.0.md#已知限制)。

提交源码的验收、十份 Node 消费者回执、WASM、六份 VSIX、八份干净 crate 打包、
完整项目试用及本地 bundle 演练均记录在候选 CI 报告。这些不能替代后续绑定 tag
的冻结或授权发布后的真实 registry 安装。没有创建 tag、发布、推进渠道或上传 Marketplace。
