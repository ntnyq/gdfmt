# gdfmt

The validated GDScript formatting facade. Output is reparsed and checked for syntax and comment preservation and idempotence.

This crate is part of the gdfmt workspace and follows its shared release version.

Grammar profiles cover Godot 4.3–4.7. Full Godot compatibility is not declared.

See the [repository](https://github.com/ntnyq/gdfmt) for usage, configuration, documentation and contribution guidelines.
